一开始这个标题起成“当我们谈论爱情时我们再谈论什么”，后来一想，其实我好像没什么资格写这种东西的。

所以就把名字改了，主要就写写这段时间的感受吧。

## <a href="#" class="headerlink" title=" "></a>

其实这段时间感触最深的就是，爱情的无常吧。

毕竟这段时间，几个哥们都和女朋友分手了，还有一个妹子也和bf分了。

有持续不到三个月半年的，也有已经两年多三年的。

有一个哥们形容分手：感觉像是玩了很久的游戏，突然被盗号了。

不过被盗号这个比喻不恰当，因为不是被绿嘛哈哈哈，倒不如用被封号来形容，可能更加好。

他对女朋友的体贴照顾我是非常敬佩的，我个人感觉，就算够不上供着一个女菩萨，也差不了多少了。

女朋友提出分手之后他也立马飞过去，带着渺茫的她能够回心转意的希望，不过结果其实早就心知肚明。

挽回，我想，不过是给自己一个交代吧。  
<span id="more"></span>

换个视角，女生提分手是怎么想的呢？

那妹子和我说:

> 没有感觉了，就分手了。这样对两个人都好。

不过显然bf还是很痴情的，一直在努力，找自己的问题。

感觉，呐，真是个很神奇的东西啊。

这也是我曾经被拒绝的理由。

## <a href="#-1" class="headerlink" title=" "></a>

我是有相当长一段时间都是单身状态了，上一段恋爱感觉都已经有些遥远了。

似乎手也没有牵过，最甜蜜的回忆也无非就是教她弹琴以及中午慢吞吞懒洋洋地去高吟吃饭。

情侣们相处的模式大多差不多吧，异地的聊出QQ的巨轮，天天煲电话粥，保持着联系。

在一所学校的呢，也无非一起上课吃饭压马路和周末娱乐。

这种我闭着眼睛都能猜出个八九不离十的恋爱桥段，在我看来，真的无聊透顶。

女孩子们总是感觉动物，可能在那么一刹那你闪着光的样子让她怦然心动，

一段时间相处下来，那种心动的感觉很可能就慢慢消逝了。

无非有的人快，有的人慢一点。

## <a href="#-2" class="headerlink" title=" "></a>

我发觉我的恋爱模式都是一开始选中一个目标，然后在追求过程中不断地给自己心理暗示，告诉自己：非她不可。

所谓选中目标，也不过是长相、声音、性格符合口味。

然后会收集很多不起眼的片段来欺骗自己，鼓励自己坚持下去。

很蠢，却也让我收获很多。

现在就特别懒，路上看的相貌不错的小姐姐，也只是在脑海里闪过:这个是我的style。

然后，就没有然后了。

因为知道追求要付出很多精力啊，而女孩子们对你的感觉在见到你第一眼就决定了。

再多的努力也只能感动自己。

不如刷刷GPA、敲敲代码，或者看会书弹会琴。

**我觉得我自己一个人过的很舒服，所以，为什么要两个人呢？**

## <a href="#-3" class="headerlink" title=" "></a>

这段时间过的其实挺糟心。

课比上学期多，宿舍的网还断了，靠着慢吞吞的CMCC-EDU残喘苟延。

入了渲染的坑，也是经常踩坑踩到怀疑人生。

还要走很长的路，留给我的时间也不是很多了。

加油吧！
